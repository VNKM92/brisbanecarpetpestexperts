## 🎬 Animation System

### Framer Motion Variants
```jsx
containerVariants: {
  - Staggered children (0.2s delay)
  - Starting from opacity: 0
}

itemVariants: {
  - Fade-in + slide-up (y: 20 → 0)
  - 0.6s duration
}

imageVariants: {
  - Fade + scale (0.95 → 1)
  - 0.8s duration
}

statsVariants: {
  - Custom index delays (i * 0.15)
  - Per-item control
}
```

## 🔧 Customization Guide

### Change Colors
```jsx
// Find in page.jsx and replace:
green-600 → your-color-600
orange-500 → your-color-500
```

### Edit Content
All content is inline - just edit the text:
```jsx
"Honest. Simple. Qleen." // Your title
"With over a decade..." // Your description
```

### Adjust Timing
Modify animation variants:
```jsx
transition: { duration: 0.6 } // Change to 0.8 for slower
```

### Customize Spacing
Adjust Tailwind classes:
```jsx
py-20 // Change to py-16 or py-24
gap-12 // Change to gap-8 or gap-16
```
